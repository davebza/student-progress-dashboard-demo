# Student Progress Dashboard Demo

A sanitized Google Apps Script portfolio project showing how structured progress data can become an actionable dashboard.

## What it demonstrates
- Google Sheets-oriented data modelling
- KPI and dashboard design
- Status logic and filtering
- Progress/history concepts
- Apps Script + browser UI
- Design for non-technical users

The names and records are fictional. No school or student data is included.

## Intended Sheet tabs
- `Learners`
- `Measures`
- `Observations`
- `StatusRules`

The demo ships with synthetic fallback records and is ready for a repository adapter to a personal Google Sheet.
